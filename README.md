# VirtuaPay – Website Frontend Case Study

A responsive website frontend project for a digital payments platform, built using HTML, CSS, JavaScript, and Sass.

**Repository:** [virtuapay-case-study](https://github.com/Lavanyav29/virtuapay-case-study)  
**Live Website:** [https://virtuapayments.com/](https://virtuapayments.com/)

## Project Overview

VirtuaPay is a website frontend project focused on presenting a digital payments platform through a structured, modern web interface.

This repository contains the website's frontend source files, page layouts, styling resources, JavaScript interactions, and visual assets.

The project is documented as a frontend development case study. It does not represent a complete payment-processing backend or a verified payment gateway implementation.

## Pages Included

The repository includes the following HTML pages:

- Home page (`index.html`)
- Alternative home page (`index-1.html`)
- About Us (`about-us-other.html`)
- Contact Us (`contact-us-other.html`)
- FAQ (`faq-other.html`)
- Login interface (`log-in.html`)
- Privacy Policy (`privacy-policy.html`)
- Terms and Conditions (`terms-conditions.html`)
- Custom 404 error page (`404.html`)

| Technology / Library | Purpose |

The repository also contains supporting fonts, icons, images, and other frontend resources.

## Running the Project Locally

This is a frontend website project.

### Option 1: Open directly

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

### Option 2: Using XAMPP

1. Place the project folder inside the XAMPP `htdocs` directory.
2. Start Apache from the XAMPP Control Panel.
3. Open the following address in your browser:

```text
http://localhost/virtuapay/
```
